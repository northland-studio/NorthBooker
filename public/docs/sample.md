# 北牖 NorthBooker

> 云端文档查看网站 · 由北域工作室开发

## 项目简介

北牖（NorthBooker）是一个基于云端的文档查看网站，支持 PDF、Word、图片、Markdown 等多种格式的在线预览。

## 功能特性

- 多格式文档在线预览
- 文档管理与分享
- 玄剑官网账号单点登录
- 分级权限管理
- 明暗双主题

## 使用说明

1. 在首页文档列表中选择要查看的文档
2. 点击文档卡片进入查看器
3. 使用顶部工具栏进行缩放、翻页、搜索等操作
4. 点击右上角图标切换明暗主题

## 权限等级

| 等级 | 含义 | 能力 |
|:---:|:---|:---|
| 0 | 普通用户 | 查看文档 |
| 1 | 管理员 | 管理文档与用户 |
| 2 | 超级管理员 | 调整用户等级 |
| 3 | 最高级 | 全部权限 |
