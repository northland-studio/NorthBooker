# 系统架构说明

## 整体架构

北牖采用前后端分离架构：

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   前端 React │ ──> │  后端 Express │ ──> │   SQLite    │
│  doc-preview │     │   REST API   │     │   存储      │
└─────────────┘     └─────────────┘     └─────────────┘
                          │
                          └──> 玄剑官网 OAuth
```

## 前端分层

- `pages/`：页面组件
- `components/`：通用组件
- `store/`：状态管理（zustand）
- `api/`：接口请求封装
- `utils/`：工具函数
- `types/`：类型定义

## 后端模块

- `routes/`：路由（文档、认证、管理）
- `middleware/`：中间件（鉴权、权限）
- `database.js`：数据库连接与初始化

## 认证流程

1. 用户点击登录，跳转玄剑官网授权
2. 玄剑官网回调携带授权码
3. 后端用授权码换取访问令牌
4. 获取用户信息并签发本地会话
